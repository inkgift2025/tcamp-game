# Penguin Character Assets

这里放小企鹅主角素材。

推荐文件：

- `penguin_spritesheet.png`
- `penguin_spritesheet.json`
- 或独立帧：`penguin_idle.png`
- `penguin_run.png`
- `penguin_jump.png`
- `penguin_double_jump.png`
- `penguin_crouch.png`
- `penguin_hurt.png`

建议尺寸：128x128 或 256x256。

风格：蓝白赛博童话，可爱企鹅，深蓝外壳，白色肚皮，橙色嘴脚，蓝色科技背包。动作轮廓必须清楚，跑步、跳跃、下滑、受击状态要容易识别。
